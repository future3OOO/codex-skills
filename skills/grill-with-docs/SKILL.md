# Grill With Docs

Use `$grilling` together with `$domain-modeling`.

This wrapper exists for compatibility with older prompts. The questioning loop
lives in `skills/grilling/SKILL.md`; durable terminology, `CONTEXT.md`, and ADR
formats live in `skills/domain-modeling/`.
